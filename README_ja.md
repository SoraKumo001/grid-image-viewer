# Quick Image Viewer

大量の画像フォルダの閲覧や漫画の読書に最適化された、Windows 向けの高速・軽量な画像ビューアです。
MassiGra に近い操作感を目指して開発されています。

- [English Documentation](README.md)

## 📥 ダウンロード

- **Microsoft Store**: [入手はこちら](https://apps.microsoft.com/detail/9ns97p3lfqws)
- **GitHub Releases**: [最新バージョン](https://github.com/SoraKumo001/quick-image-viewer/releases)

## ✨ 主な特徴

- **多彩なフォーマット**: 一般的な画像（JPG, PNG, WebP, AVIF, HEIC, JXL）からアニメーションGIF/WebPまで幅広く対応。
- **快適な動画再生**: MP4, MKV 等の主要形式に対応。
- **圧縮ファイル直接閲覧**: ZIP, CBZ, RAR, CBR, 7z 内の画像を解凍せずにそのまま表示。
- **スマートナビゲーション**: サブフォルダの自動巡回や、画像・動画が混在したフォルダのシームレスな閲覧。
- **漫画モード**: 右開き対応の見開き表示、見開きのズレ補正機能を搭載。
- **グリッド一覧**: フォルダ内の全画像をサムネイルで俯瞰。ウィンドウサイズに合わせた最適レイアウト。
- **簡易編集**: 明るさ調整や回転、フィルタ処理、切り抜き、リサイズなど。

## ⌨️ 主要なショートカット

| 操作                       | キー                                                    |
| :------------------------- | :------------------------------------------------------ |
| **次 / 前の画像**          | `Space` / `BackSpace`, `←` / `→` (またはマウスホイール) |
| **見開きのズレ補正**       | `Shift + 次 / 前の画像`                                 |
| **次 / 前のフォルダ**      | `↓` / `↑`                                               |
| **表示モード切替**         | `Ctrl + G` (単一 → 漫画 → 4分割)                        |
| **グリッド表示切替**       | `Enter`                                                 |
| **フルスクリーン**         | `F` (またはダブルクリック)                              |
| **スライドショー**         | `A` (設定画面を表示)                                    |
| **拡大 / 縮小**            | `Ctrl + ホイール` または `Ctrl + +/-`                   |
| **画像の移動**             | `Ctrl + 左ドラッグ`                                     |
| **移動・ズームのリセット** | `Ctrl + 0` (またはトップパネルのボタン)                 |
| **ブックマークパネル**     | `B`                                                     |

> [!TIP]
> すべてのキーバインドは、右クリックメニューの **General Settings** から自由に変更できます。

## 🖱️ 右クリックメニュー

以下の高度な機能にアクセスできます：

- **ファイル操作**: 名前の変更、移動、削除。
- **画像加工**: 切り抜き、リサイズ、詳細な色調補正。
- **詳細設定**: ショートカット、背景色、対象とする拡張子のカスタマイズ。

## 📋 動作要件

- Windows 10 (1809) 以降
- .NET 10.0
