# Quick Image Viewer

Windows 向けの高速・軽量な画像ビューアアプリです。フォルダ内の画像をグリッド一覧で素早く閲覧でき、見開き表示（漫画モード）にも対応しています。

## 主な機能

### 🖼️ 画像表示

- **対応フォーマット**: JPG, JPEG, PNG, BMP, GIF, WebP（アニメーション対応）, AVIF, HEIC, JPEG XL, SVG, PSD, ICO, DNG, NEF, CR2, ARW, TGA, PCX 等
- **動画再生**: MP4, WebM, MKV, MOV, AVI, WMV 形式に対応。ループ再生、音量設定に加え、動画読み込み時やマウス移動時に自動表示されるレスポンシブなシークバーを備えています。
- **圧縮ファイル直接表示**: ZIP, CBZ, RAR, CBR, 7z 形式の圧縮ファイルを解凍せずに直接閲覧可能
- **高品質スケーリング**: SkiaSharp 3.x による滑らかで高品質な画像拡大・縮小（設定で有効化可能）
- **高品質レンダリング**: SkiaSharp による高速な画像描画
- **ズーム**: Ctrl + マウスホイールで拡大・縮小
- **ドラッグ&ドロップ**: 画像ファイルやフォルダをウィンドウにドロップして開く

### 🔖 ブックマーク機能

- **お気に入り登録**: 頻繁に閲覧するフォルダをブックマークとして保存
- **クイックアクセス**: サイドパネルまたは右クリックメニューから瞬時にフォルダを切り替え。フォルダ選択後はパネルが自動的に閉じ、スムーズに閲覧を継続できます。
- **並び替え**: ブックマークパネル内でドラッグ＆ドロップによる直感的な順序変更が可能
- **スマート自動表示**: 動画の再生パネル（トランスポートコントロール）を操作中は、サイドパネルの自動表示を抑制し、UIの干渉を防ぎます。

### 🖼️ 表示モード

- **単一表示**: 1枚の画像を画面いっぱいに表示
- **2分割表示（漫画モード）**: 2ページを左右に並べて表示。右から左への読み順に対応し、見開きのズレ補正（Shift+ページ送り）も可能
- **4分割表示**: 4枚の画像を格子状（2x2）または横並び（1x4）で表示。アスペクト比に応じた自動レイアウトにも対応
- **最後尾の自動補正**: フォルダの最後の方でも、分割数に合わせたフル表示を維持するように自動調整します
- `Ctrl+G` でモードを順次切り替え可能

### 🔲 グリッドモード

- フォルダ内の全画像をサムネイルで一覧表示
- **動的レイアウト最適化**: ファイル数とウィンドウサイズに応じて、画像が最も大きく表示されるレイアウトを自動計算
- **アスペクト比対応**: フォルダ内で最も多いアスペクト比に基づいてグリッドセルの縦横比を最適化
- **スマートフォールバック**: ファイル数が多い場合は自動でスクロールモードに切り替え
- サムネイルをクリックで通常表示へ移行
- `Enter` で切り替え（カスタマイズ可能）

### 📂 フォルダナビゲーション

- **プレイリストの先読み**: 次・前のフォルダにある画像リストをバックグラウンドであらかじめ取得。フォルダ移動時の待ち時間をなくし、瞬時の切り替えを実現
- フォルダツリーを深さ優先探索で自動巡回
- 上下キーで前後のフォルダへ移動（通常モード）
- グリッドモードでは先頭行/末尾行から上下キーでフォルダ移動

### ⏱️ 自動再生（スライドショー）

- 指定した間隔（秒単位）で自動的に画像を遷移
- **クロスフェード**: 画像切り替え時に滑らかなフェード効果を適用
- **表示サイズの指定**: スライドショー時のみ特定の表示モード（全体を表示、全体を埋める、実寸表示）に自動で切り替えることが可能
- **柔軟な検索範囲**: ループ再生、ランダム順再生に加え、次のフォルダ、兄弟フォルダ、下位フォルダを自動的に含めるオプションに対応
- フルスクリーンへの自動移行オプション付き
- `A` キーで設定ダイアログを表示して開始

### 🛠️ 非破壊画像編集

- **インメモリ編集**: 元ファイルを変更せずに、表示中にリアルタイムで画像を加工
- **トーン調整**: 明るさ、コントラスト、ガンマ値をスライダーで微調整。変更は即座に反映
- **回転・反転**: 90度単位の回転、上下左右の反転に対応
- **フィルタ**: グレースケール、セピア、ネガ反転などのカラーフィルタを適用
- **ターゲット指定**: 分割表示時、右クリックした位置の画像を正確に判別して編集対象に。表示位置を維持したまま、特定の画像だけを操作可能
- **Undo/Redo**: 編集履歴を管理し、元の状態にいつでも戻すことが可能
- `Ctrl+Z` / `Ctrl+Y` で直感的な取り消し・やり直しに対応
- 編集した状態での別名保存・上書き保存が可能

### 🖨️ 印刷

- **印刷プレビュー**: OS標準の印刷ダイアログを呼び出し、印刷前にプレビューを確認可能
- **自動サイズ調整**: アスペクト比を維持したまま、用紙の印刷可能領域に収まるように自動調整

### 🎨 UI/UX

- **Mica バックドロップ**: Windows 11 のモダンな半透明デザイン
- **背景カスタマイズ**: システム（Mica）、ブラック、ホワイトから背景色を選択可能
- **カスタムタイトルバー**: アプリに溶け込むタイトルバーデザイン
- **フルスクリーン**: ダブルクリックまたは `F` キーで全画面表示を切り替え
- **範囲選択**: ドラッグで領域を選択し、右クリックからコピー
- **状態の保存**: ウィンドウサイズ・位置・表示中の画像・最後に開いていたディレクトリを次回起動時に復元
- **設定のポータビリティ**: 設定内容の JSON エクスポート/インポートに対応
- **拡張子フィルタのカスタマイズ**: 画像・動画・アーカイブの各グループごとに、表示対象とする拡張子を個別にオン/オフ可能。一括切り替えボタンにより直感的な操作が可能です。
- **操作通知**: 表示モードやストレッチモードの切り替えを画面上にオーバーレイ通知
- **マウス位置優先の操作**: 複数画像表示時、回転・削除・パスコピー等の操作はマウスカーソルが置かれている画像を優先的に対象とします

### 🌐 多言語対応

- **UIの自動ローカライズ**: システムの言語設定に基づいて、UIや通知メッセージが日本語と英語で自動的に切り替わります。
- **英語のソースコードコメント**: コードベースのコメントを英語に統一し、アクセシビリティを向上させました。

### ⌨️ ショートカットキー

| 操作                       | デフォルトキー          |
| -------------------------- | ----------------------- |
| 次の画像                   | `Space`                 |
| 前の画像                   | `BackSpace`             |
| 次のフォルダ               | `↓`                     |
| 前のフォルダ               | `↑`                     |
| 漫画モード切替             | `Ctrl+G`                |
| グリッドモード切替         | `Enter`                 |
| 自動再生（スライドショー） | `A`                     |
| ブックマークパネル切替     | `B`                     |
| メタデータ表示切替         | `I`                     |
| **フルスクリーン切替**     | `F`                     |
| **拡大 / 縮小**            | `Ctrl + +` / `Ctrl + -` |
| **ズームリセット (全体)**  | `Ctrl + 0`              |
| **実寸表示 (100%)**        | `Ctrl + 1`              |
| **右 / 左回転**            | `R` / `L`               |
| **左右反転**               | `H`                     |
| **フォルダを登録**         | `D`                     |
| **ファイルパスをコピー**   | `Ctrl + C`              |
| **ファイルを削除**         | `Delete`                |
| **表示サイズ切替**         | `S`                     |
| アプリ終了                 | `Escape`                |

- マウスホイール: 前後の画像に移動（Shiftキー押下で漫画モード時1ページ送り）
- 左右カーソルキー: 前後の画像に移動（漫画モードでは方向が反転、Shiftキー押下で1ページ送り）
- すべてのキーバインドは右クリックメニューの「Settings」からカスタマイズ可能

### 🖱️ 右クリックメニュー

モード（ビューアー / グリッド）に応じて最適な項目が自動的に切り替わります。

#### 共通・ビューアーモード項目
- **Save As**: 指定した形式（JPEG, PNG, WebP, BMP）で保存
- **Overwrite**: 上書き保存
- **Print**: 用紙サイズに合わせた画像の印刷
- **Crop**: 選択範囲の切り抜き
- **Resize**: 画像のリサイズ
- **Rotation/Flip**: 画像の回転・反転
- **Tone Adjustment**: 明るさ・コントラスト等の調整
- **Filters**: カラーフィルタの適用
- **Undo/Redo**: 編集操作の取り消し・やり直し
- **Show Metadata**: EXIF情報等の詳細表示（`I`キーで順次切り替え）
- **Bookmark**: 現在のフォルダをブックマークに追加/解除
- **File Management**: 名前の変更、別のフォルダへの移動
- **Open in Explorer**: エクスプローラーでファイルの場所を開く
- **Settings**: キーバインドや表示設定の変更

#### グリッドモード専用項目
- **Refresh Thumbnails**: サムネイルを強制的に再生成します
- **Sort By**: 名前、日付、サイズによる並び替え（UI実装中）
- **Slideshow**: 現在のフォルダからスライドショーを開始
- **Bookmarks**: フォルダ登録、パネル表示、一覧アクセス
- **General Settings**: 設定画面を即座に開く

## 動作要件

- Windows 10 (1809) 以降
- .NET 10.0

> [!NOTE]
> HEVC (H.265) や AV1 などの特定のビデオコーデックを再生するには、Microsoft Store から「HEVC ビデオ拡張機能」や「AV1 Video Extension」などのインストールが必要になる場合があります。

## ビルド

```bash
dotnet build -c Release -a x64
```

## 技術スタック

- **UI フレームワーク**: WinUI 3 (Windows App SDK 2.0)
- **アーキテクチャ**: CommunityToolkit.Mvvm による疎結合な MVVM パターン
- **画像レンダリング**: SkiaSharp 3.x
- **圧縮アーカイブ対応**: SharpCompress
- **言語**: C# (.NET 10.0)
- **設定管理**: JSON形式による永続化 (LocalApplicationData)
